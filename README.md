# English Path — จาก A1 สู่การอ่าน GED

เว็บเรียนภาษาอังกฤษด้วยตนเองสำหรับผู้ใช้ภาษาไทย มีสามส่วน: **เรียน Grammar**, **เกมการ์ดคำศัพท์และเสียง**, **ฝึกอ่านแนว GED**
ไม่ต้องสมัครสมาชิก ไม่ใช้คีย์ลับหรือบริการภายนอก (เสียงใช้ Web Speech API ของเบราว์เซอร์) ความคืบหน้าเก็บใน `localStorage` ของเครื่องนั้น

## เนื้อหาในเวอร์ชันนี้

| ส่วน | จำนวน |
|---|---|
| Grammar | 5 หมวด · 31 บท · mini-test 155 ข้อ (บทละ 5) · Post-test 50 ข้อ (หมวดละ 10) |
| คำศัพท์ | 4 ระดับ × 4 ชุด × 25 คำ = 400 คำ · คลังประโยค Post-test 400 ประโยค (1 คำ : 1 ประโยค) |
| บทอ่าน | 12 บท (RLA 4 · Science 4 · Social Studies 4) · 53 คำถาม · มีแผนภูมิ 2 บท ตาราง 1 บท |

## วิธีใช้งานในเครื่อง

- เปิด `dist/index.html` ด้วยเบราว์เซอร์ได้ทันที (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ ถ้าไม่มีจะใช้ฟอนต์ในเครื่องแทน)
- หลังแก้ไฟล์ใน `src/` ให้รัน `npm run build` (Node 18 ขึ้นไป) · ดูผลที่ `npm run dev` แล้วเปิด http://localhost:8080
- ทดสอบทั้งหมด: `npm test`
- ตรวจข้อมูล: `node test/validate.mjs`
- ทดสอบในเบราว์เซอร์: `pip install playwright && playwright install chromium && python3 test/e2e.py`

## เพิ่ม/แก้คำศัพท์ (ไม่ต้องแก้ตรรกะเกม)

แต่ละระดับอยู่ใน `src/data/vocab-xx.js` คำที่ 1–25 คือชุด 1, 26–50 ชุด 2 ไปเรื่อย ๆ แต่ละแถวเป็น

```js
['doctor', 'n', 'หมอ, แพทย์', 'I am sick. I need to see a ___.', 'ฉันป่วย ฉันต้องไปหาหมอ', ['nurse']]
//  คำ      ชนิด  ความหมายไทย   ประโยค Post-test (มี ___ หนึ่งจุด)  คำแปลประโยค        คำในชุดเดียวกันที่ "อาจเติมได้เหมือนกัน"
```

ช่องสุดท้าย (ไม่บังคับ) คือรายการคำ **ในชุดเดียวกัน** ที่ห้ามใช้เป็นตัวลวง เพื่อกันคำตอบกำกวม เช่น `door` กับ `window` ในประโยค "lock the front ___"
ความหมายไทยในชุดเดียวกันต้องไม่ซ้ำกัน และแต่ละระดับต้องมี 100 คำพอดี (`validate.mjs` จะเตือน)

## เพิ่ม/แก้บทเรียน Grammar

แต่ละหมวดอยู่ใน `src/data/grammar-*.js` บทเรียนหนึ่งบทมีโครงนี้

```js
{
  id: 'pos-noun', level: 'A1', title: 'Noun', th: 'คำนาม',
  explain: 'คำอธิบายภาษาไทย (ใส่ <b> ได้)',
  formula: 'สูตรหรือภาพจำ',
  examples: [{ en: 'n:Mali|v:has|det:a|n:cat', th: 'คำแปล' }],   // ป้าย:คำ คั่นด้วย |
  confuse: ['จุดที่มักสับสน'],
  quiz: [ /* 5 ข้อ */ ]
}
```

ป้ายในตัวอย่าง: `n pro v adj adv prep conj int det` (ชนิดคำ) หรือ `S V O C T Pl R M aux neg q` (หน้าที่ในประโยค) · `x` = ไม่ใส่ป้าย
คำถามทุกข้อ (ทั้ง mini-test และ `post`) ใช้รูปแบบเดียวกัน:

```js
{ q: 'She ___ a teacher.', o: ['is', 'are', 'am', 'be'], a: 0,
  clue: 'ดูจากคำใดในโจทย์', rule: 'กฎที่ใช้', why: 'ทำไมคำตอบนี้ถูก',
  n: ['', 'ทำไม are ผิด', 'ทำไม am ผิด', 'ทำไม be ผิด'],   // เรียงตาม o
  ex: 'ตัวอย่างเพิ่ม/ภาพจำ' }
```

ตัวเลือกจะถูกสุ่มตำแหน่งตอนแสดงผล จึงเขียนเฉลยไว้ที่ใดก็ได้ แต่ละบทต้องมี 5 ข้อ และแต่ละหมวดต้องมี `post` 10 ข้อ เรียงจากง่ายไปยาก

## เพิ่มบทอ่าน

ใน `src/data/reading.js` แต่ละบทมี `s` (ประโยคอังกฤษ), `th` (คำแปลทีละประโยค จำนวนเท่ากัน), `gloss`, `q` (คำถาม) และ `visual` (ไม่บังคับ: `bar` หรือ `table`)
ในคำถาม `ev` คือเลขประโยคที่เป็นหลักฐาน (เริ่มที่ 0) หรือ `'visual'` ถ้าตอบจากกราฟ/ตาราง เฉลยจะยกประโยคนั้นมาแสดงและไฮไลต์ในบทอ่าน

## ชื่อเล่นและตารางคะแนนสูงสุด

- ทุก Part (Grammar, คำศัพท์, ฝึกอ่าน) มีช่องใส่ชื่อเล่นด้านบน และตารางอันดับ 10 อันดับแรกด้านล่าง
- ความคืบหน้าและคะแนนแยกตามชื่อเล่น หลายคนใช้เครื่องเดียวกันได้ สลับชื่อได้จากปุ่ม "เปลี่ยนผู้เล่น"
- ชื่อเล่นแรกของเครื่องจะรับความคืบหน้าที่ทำไว้ก่อนใส่ชื่อ (รวมถึงข้อมูลจากเวอร์ชันแรก)
- คะแนนของแต่ละ Part คือผลรวมคะแนนสูงสุด: Grammar = mini-test + Post-test (เต็ม 205), คำศัพท์ = การ์ด + Post-test ของทุกชุด โดยเลือกโหมดที่ดีที่สุดของแต่ละชุด (เต็ม 640), ฝึกอ่าน = ทุกบท (เต็ม 53)
- ตารางอันดับเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่รวมข้ามเครื่อง เพราะหน้า Artifact ที่ใช้ฐานข้อมูลกลางจะแชร์เป็นลิงก์สาธารณะไม่ได้
- ทดสอบ: `python3 test/e2e_players.py`

## การทดสอบที่รันแล้ว

`validate.mjs` (Node, ผ่าน 14,840 การตรวจ): 100 คำต่อระดับ · 4×25 ต่อระดับ · 25 ประโยคต่อชุด · คำไม่ซ้ำทั้ง 400 คำ · ความหมายไทยไม่ซ้ำในชุด · mini-test 5 ข้อทุกบท · Post-test 10 ข้อทุกหมวด · ทุกตัวเลือกผิดมีคำอธิบาย · จำลองรอบการ์ด 2/3/4 ตัวเลือก × สองทิศทาง และ Post-test 300 รอบต่อชุด (15 ข้อไม่ซ้ำ, 4 ตัวเลือกไม่ซ้ำ, ไม่มีตัวลวงที่ระบุว่ากำกวม) · หลักฐานในบทอ่านชี้ประโยคที่มีอยู่จริง

`e2e.py` (Chromium headless 141 ขนาด 390×844 และ 360×740): เล่นครบ 31 บท + Post-test 5 หมวด · ปุ่มบทถัดไปกดไม่ได้จนตอบครบ · ลำดับเฉลย · การ์ด 25 ใบไม่ซ้ำในโหมด 2/3/4 ตัวเลือกและสองทิศทาง · Post-test 15 ข้อ · หน้าสรุปแยกคะแนน /25 และ /15 · โหมดทบทวนคำที่ผิด · ตอบครบ 12 บทอ่าน · ไม่มีเสียงเล่นเอง และทุกเสียงที่เรียกเป็นภาษาอังกฤษ · ข้อความช่วยเหลือเมื่อเบราว์เซอร์ไม่มีเสียง · ใช้งานได้เมื่อโหลดฟอนต์ไม่ได้และเมื่อ localStorage ถูกบล็อก · ไม่มีหน้าเลื่อนแนวนอน

## ข้อจำกัดที่ยังมี

- ทดสอบเฉพาะ Chromium แบบ headless โดยจำลองระบบเสียง ยังไม่ได้ทดสอบบน iPhone/Android จริง หรือ Safari/Firefox
- เสียงขึ้นกับเสียงภาษาอังกฤษที่ติดตั้งในอุปกรณ์ คุณภาพและสำเนียงจึงต่างกันไปตามเครื่อง
- ความกำกวมของตัวลวงตรวจจากรายการที่ระบุไว้ด้วยมือ ไม่ใช่การตรวจทางภาษาอัตโนมัติ ควรให้ครูตรวจทานอีกรอบ
- ความคืบหน้าอยู่ในเบราว์เซอร์เครื่องเดียว การซิงก์ข้ามเครื่องต้องมีระบบบัญชี (เสนอเป็นระยะถัดไป)
- บทอ่านและโจทย์ทั้งหมดแต่งขึ้นเพื่อฝึก ข้อมูลตัวเลขที่ระบุว่า "สมมุติ" ไม่ใช่สถิติจริง ข้อความจาก Declaration of Independence (1776) เป็นสาธารณสมบัติ
